# Monitor Glass

[monitor](https://github.com/monitor-probe/monitor) 的一款公开页主题，沿用经典 ServerStatus 的紧凑表格布局。

基于 [monitor-probe/monitor-theme-serverstatus](https://github.com/monitor-probe/monitor-theme-serverstatus) 修改，保留原作者与 MIT 许可。服务器行采用 Atlas v1.0.0 的中性底色和悬浮反馈，桌面行高 44px、移动端 40px。

![预览](preview.png)

## 安装

从 [Releases](https://github.com/wxte/Monitor-Glass/releases) 下载
`theme.tar.gz`，在 hub 后台「主题」页上传，或解压到 hub 的 `--themes` 目录下的 `glass/`。
之后可在同一页切换，卡片上的 ⟳ 从本仓库的最新 release 更新。
