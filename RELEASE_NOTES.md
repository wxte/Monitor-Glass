# Monitor Glass v1.0.0

Monitor Glass is ready for production use with Monitor Hub 1.3.

- Responsive server overview with searchable, sortable per-node cards.
- Node details, smooth historical resource charts, and carrier latency charts for 1 hour, 6 hours, 24 hours, and 7 days.
- Reduced motion and narrow-screen safeguards, including protection against iOS text auto-zoom breaking metric alignment.
- Deferred chart code so the home page does not load charting libraries until details or monitoring are opened.
- Installable theme archive and SHA-256 checksum are attached to this release.

Install `theme.tar.gz` from the Monitor Hub theme page. The archive includes `dist/`, `theme.json`, and `preview.png`.
